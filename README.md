A modern, high-performance, and responsive Weather Application built with **React 19**, **Vite**, and **Open-Meteo Satellite Weather API**.

Featuring real-time weather analytics, 5-day forecasts, atmospheric metric tracking, categorized quick-city selection (focusing on **Prayagraj**, **Uttar Pradesh**, **India Metros**, and **Global Cities**), and dynamic CSS animated backgrounds (Sun rays, Rain, Floating clouds, Thunderstorm, Snow, and Fog/Haze).

## ✨ Features

- 📍 **1-Click Quick City Pills:**
  - **Prayagraj & Local:** Prayagraj, Naini, Phaphamau, Jhunsi, Handia, Karchhana, Soraon, Mau Aima.
  - **Uttar Pradesh:** Lucknow, Varanasi, Ayodhya, Kanpur, Noida, Gorakhpur, Agra, Mathura, Bareilly, Meerut, Jhansi, Aligarh.
  - **India Metros:** New Delhi, Mumbai, Bengaluru, Kolkata, Hyderabad, Chennai, Jaipur, Ahmedabad, Pune, Chandigarh.
  - **Global Cities:** Dubai, London, New York, Tokyo, Paris, Singapore, Sydney.
- 🔍 **Intelligent Live Search:** Search any town, city, or village worldwide with smart local UP/India disambiguation.
- 🎨 **Dynamic Animated Weather Backgrounds:**
  - Warm sun rays for clear sunny days
  - Realistic animated falling raindrops for rainy weather
  - Soft floating clouds for overcast days
  - Electric lightning flash for thunderstorms
  - Gentle falling snowflakes for snow
  - Ambient gradient for haze/mist/fog
- 📊 **Comprehensive Weather Metrics:**
  - Temperature in **°C** or **°F** (instant toggle)
  - Humidity percentage & category (Low / Moderate / High)
  - Wind speed (km/h) & compass direction (N, NE, SW, etc.)
  - Atmospheric pressure (hPa)
  - Visibility range (km)
  - Accurate local Sunrise & Sunset times
- 📅 **5-Day Future Forecast:** Daily high/low temperature cards and weather icons.
- ⚡ **Zero Setup & Out-of-the-Box:** Runs immediately with accurate global satellite data without requiring any paid API keys.

## 🚀 Tech Stack

- **Frontend:** React 19, JavaScript (ES6+), Modern CSS3 / Glassmorphism
- **Build Tool:** Vite 6
- **Hosting & CI/CD:** GitHub Pages + GitHub Actions
- **Data Source:** Open-Meteo Satellite & Geocoding APIs
- **Icons & Graphics:** Custom lightweight responsive SVGs & CSS animations

## 🛠️ Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sonampandey111/WeatherApi.git
   cd WeatherApi
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
